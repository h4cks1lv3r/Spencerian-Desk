# Reviewed clean study drawings

These SVG files are the editable, authoritative drawing inputs used by `build_examples.py` when a model has a `vectorOverride` in `lesson-examples.json`. They contain local vector paths and plain white backgrounds, without embedded page photos.

The manifest records the physical source page, selection coordinates, and reconstruction method. The app identifies these examples as redrawn from the source book. The drawings preserve source-based letter constructions or exercise patterns while removing scanning damage; they are not facsimiles of untouched page crops.

The three progressive drills (`a02.svg`, `a06.svg`, and `x02.svg`) regularize the selected oval, compound-curve, and spiral patterns. `r01.svg` redraws the Key’s heavy-to-fine straight shade with a 52-degree axis and clean rules. The bird stages isolate routes from one source-guided figure; the verse and combined page are reviewed teaching drawings derived from their cited plates.

For a later revision, edit these paths directly or rebuild a candidate from the documented sources, then compare the full-size result with the source and verify the lesson’s letter forms, small counters, dots, joins, and shading before replacing a reviewed drawing. Re-running the standard atlas builder copies the reviewed SVGs unchanged.
