# Classic stationery theme — 1.1.0

The theme keeps the existing Spencerian Lab learning structure and interaction model. It changes the interface presentation throughout the home, course, lesson, practice, atlas, tools, signature, progress and settings screens.

- Warm white and ivory surfaces: #fffdf8 and #f4f1eb.
- Dark ink for body text and primary actions: #262d2a / #263d33.
- Antique gold detail: #876733, with fine ruled borders and quiet decorative flourishes.
- EB Garamond headings, bundled offline under SIL Open Font License. System sans-serif remains for controls and long lesson text.
- Folded page corner and stacked sheets on the main lesson card; a small fold above the practice canvas stays outside the drawing area.
- Consistent light native Android dialogs, system bars, and a matching launcher icon.

The curriculum, 52-degree guide geometry, lesson content and progress schema are unchanged.

Font source: https://github.com/google/fonts/tree/main/ofl/ebgaramond
