# Authentic home specimen

Version 1.1.2 replaces the abstract SVG line drawing in the home next-lesson card with the actual word “Specimen” from the historical reference already bundled with the course.

- Source: *New Spencerian Compendium*, P. R. Spencer’s Sons.
- Location: printed Plate 5, physical PDF page 76; Lesson 8, third copy.
- Original line: “Specimen of my plain penmanship”.
- Bundled image: `app/src/main/assets/plates/capital-ovals.jpg`, 3000 × 2261 pixels.
- Atlas ID: `capital-ovals`.
- Display viewport: `600 650 516 190` in source-image coordinates.
- Reference: https://archive.org/details/NewSpencerianCompendium

The SVG displays the original scan through a viewport; it contains no redrawn letter paths or substituted script font. The bundled JPG is unchanged. The crop preserves the complete capital, lowercase letters, and final n exit stroke, stopping before the next word’s entry. Layout padding gives the word breathing room without admitting neighboring lettering. The image retains the original proportions. Multiplication blending lets the scan paper sit naturally on the warm white card.

The visible caption identifies Plate 5. Tapping the specimen or “View original plate” opens the existing offline plate viewer, which provides the complete scan, source name, and physical/printed page references. The original Continue learning action remains available above it.

The figure has no fixed maximum height, so the caption can fit at the existing mobile breakpoint. The button and SVG have accessible labels and the button inherits the visible keyboard-focus treatment.
